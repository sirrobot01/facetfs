# Security policy

FacetFS is pre-release software and currently serves no network protocols. No
version is supported for production use yet.

Please report suspected vulnerabilities privately to the repository maintainer
instead of opening a public issue. Include the affected commit, impact,
reproduction steps, and any suggested mitigation. A dedicated reporting address
will be published before the first experimental network release.

Never include passwords, private keys, bearer tokens, raw NTLM material, or
personal filesystem data in a report or test fixture.
